# Қонақүйді брондау ақпараттық жүйесі

## Жоба туралы

Бұл жоба қонақүй бөлмелерін онлайн брондауды ұйымдастыруға арналған.

## Жобаның мақсаты

Қолданушыға қонақүйді таңдау, бос бөлмені көру,
брондауды рәсімдеу және брондау ақпаратын басқару мүмкіндігін беру.

## Негізгі функциялар

- Қонақүйді таңдау
- Бос бөлмелерді көру
- Бөлмені брондау
- Брондау ақпаратын енгізу
- Брондауды өзгерту
- Брондауды жою
- Брондау тарихын көру
