# Use Case

## Актор

Негізгі актор — Қонақүй клиенті.

## Use Case сценарийлері

### 1. Жүйеге кіру

Қолданушы жүйеге логин және пароль арқылы кіреді.

### 2. Қонақүйді таңдау

Қолданушы қонақүйді таңдайды.

### 3. Бөлмені іздеу

Қолданушы қажетті күндерді енгізеді.
Жүйе бос бөлмелерді көрсетеді.

### 4. Бөлмені брондау

Қолданушы бөлмені таңдап, брондау мәліметтерін енгізеді.

### 5. Брондауды растау

Жүйе брондау ақпаратын сақтайды және
қолданушыға брондаудың сәтті орындалғанын көрсетеді.

### 6. Брондауды жою

Қолданушы өз брондауын жоя алады.
## Брондау нәтижесі

Брондау сәтті орындалған кезде жүйе қолданушыға:

"Брондау сәтті орындалды"

деген хабарлама көрсетеді.
